# Telegram Scheduled Image Reposter

Автоматический мониторинг 11 каналов-доноров и отложенный постинг в канал `@LoverTea228_2` по расписанию:
⏰ **Каждый час в :05, :25 и :45 минут** (3 раза в час).

## Как это работает:
1. **Фоновый сбор**: Скрипт непрерывно проверяет открытые каналы-доноры раз в минуту.
2. **Фильтрация рекламы**: Посты со ссылками (`t.me/`, `@`), словами `реклама`, `erid`, `промокод`, `скидка` и др. автоматически отсеиваются.
3. **Исключение повторов**: Каждая картинка проверяется по хэшу (MD5). Одинаковые мемы не попадут в очередь дважды.
4. **Умная очередь**: Одобренные картинки скачиваются в папку `images_queue` и встают в очередь (`queue.json`).
5. **Публикация по часам**: Ровно в :05, :25 и :45 минут бот берет следующий мем из очереди и выкладывает его в канал.

## Запуск:
Просто запустите [`start.bat`](start.bat) двойным кликом мыши. Окно сверните — бот будет работать в фоне.
